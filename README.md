# Raid Lead Assist

Raid Lead Assist is a manual raid-leader callout panel for The Venomous Abyss. Encounter strategy data remains source-reviewed, not live Heroic-validated, until the raid has been tested on the live Retail client.

## Validation

GitHub Actions compile every Lua file with Lua 5.1, verify the active TOC inventory, and run focused behavioral regressions for saved-variable schema safety, Midnight secret-value handling, Blizzard Encounter Timeline invalid-event races, multi-provider timer selection/deduplication, acknowledgement, and raid-warning pre-pull cancellation.

These automated checks are controlled-runtime evidence. They do not replace a live Retail raid test with Blizzard timelines, BigWigs and DBM present.
